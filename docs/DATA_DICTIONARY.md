# Data Dictionary

## Financial Document Intelligence & RAG Analytics Platform

---

This document defines every major data field used across the platform.

---

## Document Fields

| Field | Description | Data Type | Example | Required | Source |
|---|---|---|---|---|---|
| `document_id` | Unique identifier for an uploaded document | UUID | `a1b2c3d4-e5f6-7890-abcd-ef1234567890` | Yes | System-generated |
| `filename` | Original name of the uploaded PDF file | VARCHAR(500) | `ABC_Annual_Report_2025.pdf` | Yes | User upload |
| `file_hash` | SHA-256 hash of the file content for duplicate detection | VARCHAR(64) | `e3b0c44298fc1c149...` | Yes | System-computed |
| `company` | Name of the company the document belongs to | VARCHAR(255) | `ABC Ltd.` | No | User input or auto-detected |
| `financial_year` | Financial reporting period covered by the document | VARCHAR(20) | `FY2025` | No | User input or auto-detected |
| `document_type` | Classification of the document | VARCHAR(50) | `annual_report` | No | User input |
| `status` | Current processing state of the document | VARCHAR(20) | `PROCESSED` | Yes | System-managed |
| `page_count` | Total number of pages in the PDF | INTEGER | `245` | No | Extracted during processing |
| `file_size_bytes` | Size of the uploaded file in bytes | BIGINT | `4523981` | Yes | Measured at upload |
| `storage_path` | Filesystem path where the PDF is stored | VARCHAR(1000) | `./data/uploads/a1b2c3d4.pdf` | Yes | System-generated |
| `upload_date` | Timestamp when the document was uploaded | TIMESTAMP | `2026-09-10T12:30:00Z` | Yes | System-generated |
| `processed_date` | Timestamp when processing completed | TIMESTAMP | `2026-09-10T12:32:15Z` | No | System-generated |

**Valid `status` values**: `UPLOADED`, `PROCESSING`, `PROCESSED`, `FAILED`

**Valid `document_type` values**: `annual_report`, `quarterly_report`, `earnings`, `presentation`, `statement`

## Chunk Fields

| Field | Description | Data Type | Example | Required | Source |
|---|---|---|---|---|---|
| `chunk_id` | Unique identifier for a text chunk | UUID | `f1e2d3c4-b5a6-7890...` | Yes | System-generated |
| `document_id` | Parent document this chunk belongs to | UUID | `a1b2c3d4-e5f6-7890...` | Yes | Foreign key to documents |
| `chunk_index` | Sequential position of the chunk within the document | INTEGER | `47` | Yes | Assigned during chunking |
| `content` | The actual text content of the chunk | TEXT | `"Revenue for FY2025 was..."` | Yes | Extracted from PDF |
| `page_number` | Source page number in the original PDF | INTEGER | `87` | Yes | Tracked during extraction |
| `section` | Detected document section containing this chunk | VARCHAR(255) | `Income Statement` | No | Detected by SectionDetector |
| `char_start` | Character start position in the full document text | INTEGER | `45230` | No | Computed during chunking |
| `char_end` | Character end position in the full document text | INTEGER | `47890` | No | Computed during chunking |
| `token_count` | Approximate token count for the chunk | INTEGER | `512` | No | Computed during chunking |
| `embedding` | 384-dimensional vector representation of the chunk | VECTOR(384) | `[0.023, -0.156, ...]` | No | Generated by embedding model |

## Financial Metric Fields

| Field | Description | Data Type | Example | Required | Source |
|---|---|---|---|---|---|
| `metric_id` | Unique identifier for an extracted metric | UUID | `b2c3d4e5-f6a7-8901...` | Yes | System-generated |
| `document_id` | Source document the metric was extracted from | UUID | `a1b2c3d4-e5f6-7890...` | Yes | Foreign key to documents |
| `metric_name` | Standardized name of the financial metric | VARCHAR(100) | `revenue` | Yes | Assigned by MetricExtractor |
| `value` | Numerical value of the metric | DECIMAL(20,4) | `11450.0000` | Yes | Extracted from document |
| `period` | Financial period the metric applies to | VARCHAR(20) | `FY2025` | Yes | Extracted from document |
| `unit` | Unit of measurement | VARCHAR(50) | `INR Crore` | Yes | Extracted from document |
| `currency` | Currency code | VARCHAR(10) | `INR` | No | Extracted or assumed |
| `confidence` | Confidence score of the extraction (0.0–1.0) | FLOAT | `0.92` | Yes | Assigned by MetricExtractor |
| `source_page` | Page number where the metric was found | INTEGER | `87` | No | Tracked during extraction |

**Valid `metric_name` values**: `revenue`, `gross_profit`, `ebitda`, `operating_income`, `net_income`, `eps`, `total_assets`, `total_liabilities`, `total_debt`, `cash`, `operating_cash_flow`, `free_cash_flow`

## Analysis Result Fields

| Field | Description | Data Type | Example | Required | Source |
|---|---|---|---|---|---|
| `analysis_id` | Unique identifier for the analysis | UUID | `c3d4e5f6-a7b8-9012...` | Yes | System-generated |
| `document_id` | Analyzed document | UUID | `a1b2c3d4-e5f6-7890...` | Yes | Foreign key to documents |
| `health_score` | Composite financial health score (0–100) | DECIMAL(5,2) | `78.00` | No | Computed by HealthScoreEngine |
| `dimension_scores` | Sub-scores per dimension (JSONB) | JSONB | `{"growth": {"score": 86.0}}` | No | Computed by HealthScoreEngine |
| `risk_summary` | Identified risks as structured array (JSONB) | JSONB | `[{"category": "Financial", ...}]` | No | Generated by RiskAnalyzer |
| `ai_insights` | AI-generated key findings (JSONB) | JSONB | `[{"insight": "Revenue grew...", ...}]` | No | Generated by LLM |
| `generated_at` | Timestamp when analysis was generated | TIMESTAMP | `2026-09-10T12:32:15Z` | Yes | System-generated |

## Risk Fields (within `risk_summary` JSONB)

| Field | Description | Data Type | Example | Required | Source |
|---|---|---|---|---|---|
| `risk_id` | Unique identifier for the risk | UUID | `d4e5f6a7-b8c9-0123...` | Yes | System-generated |
| `category` | Risk classification | STRING | `Financial` | Yes | Assigned by RiskAnalyzer |
| `description` | Human-readable risk description | STRING | `Significant increase in long-term debt` | Yes | Generated by RiskAnalyzer |
| `severity` | Impact assessment | ENUM | `High` | Yes | Assigned by RiskAnalyzer |
| `evidence` | Supporting text excerpt from document | STRING | `"Total borrowings increased by 34%..."` | Yes | Extracted from document |
| `source_page` | Page number of the evidence | INTEGER | `103` | No | Tracked during extraction |
| `section` | Document section containing the evidence | STRING | `Risk Factors` | No | Detected by SectionDetector |
| `confidence` | Confidence of the risk identification (0.0–1.0) | FLOAT | `0.87` | Yes | Assigned by RiskAnalyzer |

**Valid `category` values**: `Financial`, `Market`, `Operational`, `Regulatory`, `Credit`, `Liquidity`, `Business`

**Valid `severity` values**: `High`, `Medium`, `Low`
