## 1. Overview

The frontend is a Streamlit multi-page application providing five primary views. The application communicates with the FastAPI backend via HTTP calls.

### Design Principles

| Principle | Implementation |
|---|---|
| **Clarity** | Financial data displayed in familiar formats (KPI cards, tables, charts) |
| **Transparency** | Every AI output includes source citations and methodology links |
| **Responsiveness** | Processing status visible; loading states for async operations |
| **Progressive disclosure** | Summary first, details on demand |

## 2. Navigation

Streamlit sidebar navigation with the following pages:

| # | Icon | Page Name | Path | Description |
|---|---|---|---|---|
| 1 | 📊 | Dashboard | `pages/1_📊_Dashboard.py` | Company overview, health score, KPIs, risks |
| 2 | 📄 | Upload | `pages/2_📄_Upload.py` | Document upload and management |
| 3 | 📈 | Analysis | `pages/3_📈_Analysis.py` | Detailed financial metrics, ratios, charts |
| 4 | 🤖 | AI Analyst | `pages/4_🤖_AI_Analyst.py` | Natural-language Q&A chat interface |

### Sidebar Components

- Application logo/title
- Page navigation (auto-generated by Streamlit)
- Document selector dropdown (select active document for analysis)
- System status indicator (healthy/degraded)

### Layout

```
┌─────────────────────────────────────────────────────────────┐
│  📄 Document Management                                     │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─── Upload New Document ──────────────────────────────┐  │
│  │                                                       │  │
│  │  ┌─────────────────────────────────────────────┐     │  │
│  │  │                                             │     │  │
│  │  │     📎 Drag and drop your PDF here          │     │  │
│  │  │        or click to browse                    │     │  │
│  │  │                                             │     │  │
│  │  │     Accepted: PDF (max 50 MB)               │     │  │
│  │  └─────────────────────────────────────────────┘     │  │
│  │                                                       │  │
│  │  Company: [________________]  (optional)              │  │
│  │  Financial Year: [________]   (optional)              │  │
│  │  Document Type: [▼ Annual Report         ]            │  │
│  │                                                       │  │
│  │  [ 📤 Upload & Process ]                              │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  📋 Uploaded Documents                                      │
│                                                             │
│  ┌──────────────────┬──────────┬────────┬────────┬───────┐ │
│  │ Filename         │ Company  │ Year   │ Status │ Action│ │
│  ├──────────────────┼──────────┼────────┼────────┼───────┤ │
│  │ ABC_AR_2025.pdf  │ ABC Ltd. │ FY2025 │ ✅ DONE│ 🗑️   │ │
│  │ ABC_AR_2024.pdf  │ ABC Ltd. │ FY2024 │ ✅ DONE│ 🗑️   │ │
│  │ XYZ_Q3_2025.pdf  │ XYZ Corp │ Q3'25  │ ⏳ ...  │ —    │ │
│  └──────────────────┴──────────┴────────┴────────┴───────┘ │
└─────────────────────────────────────────────────────────────┘
```

### Components

| Component | Behavior |
|---|---|
| **File uploader** | Streamlit `file_uploader` with drag-and-drop; accepts `.pdf` only |
| **Metadata inputs** | Optional text inputs for company name, financial year; dropdown for document type |
| **Upload button** | Uploads file via `POST /documents/upload`, then triggers `POST /documents/{id}/process` |
| **Processing indicator** | Streamlit spinner or progress bar during processing |
| **Document table** | Lists all documents with status badges and delete buttons |
| **Delete action** | Confirmation dialog before `DELETE /documents/{id}` |

### Validation

| Check | Message |
|---|---|
| Non-PDF file | "Only PDF files are accepted" |
| File > 50 MB | "File size exceeds the 50 MB limit" |
| Duplicate file | "This document has already been uploaded" |
| Upload failure | "Upload failed. Please try again" |

### Status Badges

| Status | Badge | Color |
|---|---|---|
| UPLOADED | ⬜ Uploaded | Gray |
| PROCESSING | ⏳ Processing | Yellow |
| PROCESSED | ✅ Processed | Green |
| FAILED | ❌ Failed | Red |

### Components

| Component | Description |
|---|---|
| **Document selector** | Dropdown to filter queries to a specific document or search all |
| **Suggested questions** | Clickable pre-defined financial questions (4–6 suggestions) |
| **Chat history** | Scrollable message list showing user questions and AI responses |
| **Response display** | Answer text + collapsible source citations + performance metadata |
| **Input field** | Text input with send button; supports Enter key submission |

### Interaction Behaviors

| Action | Behavior |
|---|---|
| Submit question | Shows spinner, calls `POST /query`, displays response |
| Click suggested question | Fills input field with the question text |
| Click source citation | Expands to show the source chunk text (if available) |
| No results | Shows: "The requested information could not be found in the uploaded documents" |
| API error | Shows: "The AI service is temporarily unavailable. Please try again" |
